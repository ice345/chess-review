# R3 · 局面回顾与棋库备份

2026-09-06；承接 R1、R2 的未提交工作。R3 工程实现和本地验收完成。

## 实际行为

Start review 打开第一处未回顾的源着法；用户在该局面的客观证据加载后明确确认，才保存 `gameId + ply + reviewedAt`。Next position、Pause、Continue 支持同盘和跨盘继续。重复打开或重复确认不增加计数。完整回顾与历史手动完成分别标注；没有答题评分、掌握度或棋力提升声明。

Settings → Local data 增加 JSON v1 棋库备份与恢复预览，保存 PGN/FEN、原始 PGN、偏好与训练进度。默认保留本浏览器重复记录；选择使用备份会明确覆盖同 ID 的旧进度。输入完整校验通过后才事务写入；其他标签页的新进度会使旧预览失效。恢复暂停后台工作并要求重新加载。缓存、账号凭据/会话、头像与任务运行日志不导出，恢复后的任务即使没有缓存也可访问。

偏好存储与棋库事务分开处理：棋库恢复成功但 localStorage 失败，会保留待恢复偏好并提示重试。数据库升级被另一页阻塞或后续请求排队时有恢复提示，迟到连接会关闭。

细节见 [备份协议与边界](../library-backup.md)、[训练模型](../advanced-study.md)。

## 保留边界

没有变更棋子、配色、着法图标或 Accuracy/分类/评分视角等棋类算法。没有部署或提交。备份上限 50 MiB，每集合 10,000 条；大型棋库性能与其他浏览器/真实设备属于 R5。下一批 R4 处理公开能力表达、平台接口保护、帮助与数据说明。
