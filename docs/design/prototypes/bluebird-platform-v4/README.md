# Bluebird Platform v4 — 全平台布局研究

状态：独立设计原型，不是生产应用，不连接真实棋谱库、AI、引擎或外部账号。

## 打开

直接打开 `index.html`，或从仓库根目录运行：

```sh
python3 -m http.server 3014 --bind 127.0.0.1 --directory docs/design/prototypes/bluebird-platform-v4
```

访问 http://localhost:3014 。右上角“逐页预览”切换 14 个画面。

## 范围

- 完整布局方向：书桌、导入、棋谱库、引导复盘、着法、讲解、引擎、笔记、完成、练习、成长、设置、帮助、分享。
- 可操作：路由切换、棋谱搜索及无结果状态、details 展开、当前会话内笔记保存。
- 不包含：真实解析、引擎调用、走子、数据持久化、同步、上传、导出。设置控件只展示排版。
- 示例棋局标题/统计与静态 `1.e4` 棋盘仅用于构图，不是一份匹配的真实分析报告。
- 原型以重建结构为目的，部分面板是说明型占位内容；正式产品需接入完整真实状态和功能。
- 全文设计规格：[整体重设计方案](../../proposals/2026-09-23-bluebird-platform-redesign.md)。

## 2026-09-23 实际验证

通过真实浏览器 UI 工具检查，而非截图基线自动更新：

- 1280px、390px、320px：逐一切换全部 14 个画面，DOM 测量均无页面横向溢出。
- 1280px：逐页检查图片加载，没有损坏的棋子图片。
- 截图视觉检查：首页、复盘、设置、棋谱搜索无结果；390px 首页；320px 复盘。
- 发现并修正：棋盘各行被图片固有尺寸撑开；手机首页插画进入正文安全区；程序聚焦主区产生不必要的大外框。
- 交互确认：搜索不存在的关键词后出现无结果说明；笔记输入并保存后显示“已记录在本次设计预览中”。
- `node --check .../app.js` 通过。
- 针对 app.js 的 ESLint 首次提示缺少浏览器全局声明，已明确声明 document/location/window 后重跑。
- `git diff --check` 通过；新文件独立于现有生产修改。

未覆盖：所有页面逐张视觉截图、768/1024/1440 宽、系统减少动态实际切换、完整键盘/读屏、真实产品数据与服务状态。CSS 已提供减少动态规则，但不能据此声称完成系统偏好验收。

本轮没有生产代码改动，因此未重复运行 web 包测试、类型检查或生产构建；原型只有无依赖 HTML/CSS/JS，不参与 Next.js 编译。生产迁移时仍需按仓库要求完整验证。
